The essentials, without the clutter.

TellyBox Protect is being built around a small set of features that matter for a reliable everyday VPN.

⚡

Fast WireGuard tunnel

The Android client uses the official WireGuard tunnel library rather than a custom VPN protocol.

🔐

Device-owned private keys

The client private key is generated and kept locally. Only the public key is registered with the backend.

📱

Simple Android experience

Account login, VPN permission, connect, disconnect and status are being designed as a straightforward mobile flow.

🌐

Secure account API

The production Android app communicates with the backend over HTTPS at a dedicated API endpoint.

Security architecture

Your VPN identity starts on your device.

TellyBox Protect separates the Android device identity from the server configuration. The backend receives the public key it needs to create a WireGuard peer; the private key remains local to the device.

01

Local key generation
WireGuard key material is created on the Android device.

02

Encrypted local persistence
Account-scoped configuration and identity data use Android Keystore-backed storage.

03

Restricted server boundary
The backend uses a narrowly scoped privileged helper for WireGuard peer management.

About the project

Frequently asked questions

Is TellyBox Protect available to download yet?

Not publicly yet. It is currently an active development and device-testing project.

What VPN technology does it use?

WireGuard. The Android project uses the official WireGuard Android tunnel library.

Does the server receive my private WireGuard key?

No. The architecture is designed so the client private key remains on the Android device and the backend receives only the corresponding public key.

Is the project open source?

The public project website is hosted from GitHub. Repository visibility and release source availability may change as development progresses.
