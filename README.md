# TellyBox Protect

Public website for the TellyBox Protect Android VPN project.

## Website

This repository contains a lightweight static landing page designed for GitHub Pages.

Main files:

- `index.html` — site content
- `styles.css` — responsive styling
- `.nojekyll` — serve the static files directly through GitHub Pages

## Current project status

TellyBox Protect is in active development. The Android app currently authenticates against the deployed HTTPS backend and can register a backend-managed WireGuard peer. Real Android tunnel startup and connection lifecycle work are the current focus.

## Publishing with GitHub Pages

GitHub Pages can publish directly from the `main` branch, repository root.
